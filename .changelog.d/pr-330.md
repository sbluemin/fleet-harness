### fleet-plugin
#### Added
- [fleet-console] Point the Repository panel at any git worktree or nested repository under the Theater and keep the selection per Theater.
  ko: Repository 패널을 Theater 하위의 git 워크트리나 중첩 저장소로 전환하고 선택을 Theater별로 유지합니다.
- [fleet-console] Show the active repository and its branch above the Repository panel, marked while a sub-context is selected.
  ko: 활성 저장소와 브랜치를 Repository 패널 상단에 표시하고 하위 컨텍스트 선택 중임을 함께 나타냅니다.

#### Fixed
- [fleet-console] Restore the Repository panel source navigation background that an undefined theme token left transparent.
  ko: 정의되지 않은 테마 토큰 때문에 투명하게 남아 있던 Repository 패널 소스 내비게이션 배경을 복원합니다.
