### fleet-console
#### Changed
- The Claude (Gateway) launch menus now group enabled models under provider bands with the matching provider glyph, show short model names without the provider prefix, and open reasoning-effort choices in a nested submenu on model hover while a plain model click still launches with the fallback. Each menu is sized to the names it carries, and a submenu always opens outward from the box that owns it, so exactly one effort list is on screen and it never lands back on top of the menu you opened it from.
