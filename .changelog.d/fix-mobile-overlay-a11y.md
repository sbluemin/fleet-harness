### fleet-mobile
#### Fixed
- VoiceOver can now reach and activate Try again, Back to, and All consoles separately on the connection and error screens, while the status message is still read as one item.
  ko: 연결·오류 화면에서 VoiceOver로 Try again·Back to·All consoles 버튼을 각각 찾아 누를 수 있으며, 상태 문구는 여전히 한 번에 읽힙니다.
- Screen readers no longer reach the hidden Console behind the connection screens or the Consoles list.
  ko: 연결 화면이나 Consoles 목록이 떠 있는 동안 스크린 리더가 뒤에 가려진 Console로 이동하지 않습니다.
