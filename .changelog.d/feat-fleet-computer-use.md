### fleet-console
#### Changed
- On macOS, agents can use apps in the background with a separate Fleet cursor that leaves your pointer alone. Computer Use now requires the Fleet Console desktop app on macOS and is no longer available on Windows or Linux.
  ko: macOS에서는 에이전트가 내 포인터를 건드리지 않고 Fleet 전용 커서로 백그라운드에서 앱을 사용할 수 있습니다. 이제 컴퓨터 사용은 macOS용 Fleet Console 데스크톱 앱이 필요하며 Windows와 Linux에서는 사용할 수 없습니다.
