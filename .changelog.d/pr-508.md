### fleet-console
#### Changed
- [fleet-console] Replace the command band's six map controls with one Cruise / Tactical / War Room mode switch that always names the active canvas mode, plus a tray holding only that mode's own tools: view reset and fit-all for Cruise, the grid, columns and rows layouts for Tactical. The three mode names are product terms and stay in English in every locale, so the band, mode curtains, empty-state hints, command palette and shortcut list all use the same word. Every mode arrival draws the same curtain titled with that name alone, and returning to Cruise now draws it too instead of slipping back unannounced.
  ko: 커맨드 밴드의 맵 컨트롤 6개를 Cruise / Tactical / War Room 모드 스위치 하나로 대체해 현재 캔버스 모드를 항상 이름으로 밝히고, 그 모드 전용 도구만 옆 트레이에 둡니다. Cruise는 보기 초기화와 모든 패널 맞춤을, Tactical은 격자·열·행 레이아웃을 갖습니다. 세 모드 이름은 제품 고유 명칭이라 모든 로케일에서 영문 그대로이며, 밴드·모드 커튼·빈 화면 힌트·명령 팔레트·단축키 목록이 같은 낱말을 씁니다. 모드 도착은 모두 그 이름만 실은 같은 커튼으로 알리며, Cruise로 돌아올 때도 이제 조용히 스며들지 않고 같은 커튼을 칩니다.

- [fleet-console] Move the triage Spotlight and deck density controls out of the canvas rail into the War Room tray, so every mode keeps its own tools in the same place on the band. Both are icons now; the density control keeps its zoom readout and drops its label.
  ko: 선별 처리의 스포트라이트와 덱 밀도 컨트롤을 캔버스 레일에서 War Room 트레이로 옮겨, 모든 모드가 자기 도구를 밴드의 같은 자리에 두게 했습니다. 둘 다 아이콘으로 바뀌었고, 밀도 컨트롤은 배율 표시는 유지하고 낱말만 뺐습니다.

#### Fixed
- [fleet-console] Stop a layout button from silently dropping War Room mode: the layout controls now exist only while Tactical is the active mode, so pressing one can no longer end triage without warning.
  ko: 레이아웃 버튼이 War Room 모드를 조용히 끝내던 문제를 고쳤습니다. 레이아웃 컨트롤은 Tactical이 활성일 때만 존재하므로, 눌러서 선별 처리가 경고 없이 종료되는 일이 사라집니다.
- [fleet-console] Stop offering Reset canvas view in War Room mode, where the viewport transform is disabled and the control did nothing when pressed.
  ko: War Room 모드에서 캔버스 보기 초기화를 더 이상 제공하지 않습니다. 이 모드는 뷰포트 transform이 꺼져 있어 눌러도 아무 변화가 없었습니다.
