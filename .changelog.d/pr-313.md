### fleet-plugin

#### Changed

- [fleet-console] Session Analyst artifacts now render as full web pages inside an isolated sandboxed iframe, so SVG, inline CSS, canvas, and inline scripts display like a normal browser page instead of a stripped-down static subset; the artifact still cannot reach the Console, its data, or its cookies.
