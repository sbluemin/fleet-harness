### fleet-console
#### Added
- Add Computer Use for local macOS Agents through the installed ChatGPT/Codex runtime, with opt-in under experimental AI extensions in Settings, searchable app targets, reusable action schemas, session-scoped access, and actionable status and recovery guidance.
  ko: 설치된 ChatGPT/Codex 런타임을 통해 로컬 macOS 에이전트가 앱을 읽고 조작하는 Computer Use를 추가했습니다. Settings의 실험 기능 내 AI 확장에서 켤 수 있으며, 앱 대상 검색·동작 스키마 재사용·세션별 접근과 상태·복구 안내를 제공합니다.

### fleet-desktop
#### Added
- Declare macOS automation permission so the opt-in Computer Use runtime can request access to the installed ChatGPT/Codex service from the Desktop shell.
  ko: Desktop 셸에서 옵트인한 Computer Use 런타임이 설치된 ChatGPT/Codex 서비스에 접근 권한을 요청할 수 있도록 macOS 자동화 권한을 선언했습니다.
