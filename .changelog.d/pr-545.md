#### Fixed
- [core-ai-gateway] Tool-call arguments returned over the OpenCode Chat Completions wire now drop keys the tool's own schema never declared, so a model that invents an extra field no longer fails a schema-validated call. That backend accepts `strict: true` and ignores it, so the schema is enforced on the way in instead.
