### fleet-cli
#### Changed
- [fleet-cli] Let the Admiral host author and mutate Fleet Plans directly while keeping task completion marking exclusive to Ohio.
  ko: 제독 호스트가 Fleet Plan을 직접 작성·변경하도록 하고, 태스크 완료 표시는 Ohio 전용으로 유지합니다.

### fleet-plugin
#### Changed
- [fleet-console] Expose host-owned Fleet Plan authoring in Console Agent sessions while keeping Carrier Plan mutation fail-closed.
  ko: Console Agent 세션에서 호스트 소유 Fleet Plan 작성을 제공하고, Carrier의 Plan 변경은 실패 폐쇄 방식으로 차단합니다.

### fleet-core
#### Breaking Changes
- [fleet-admiral] Move Kirov from Fleet Plan authoring to optional read-only Plan assurance; Kirov dispatches now require `plan_ref` instead of `plan_id`.
  ko: Kirov를 Fleet Plan 작성자에서 선택적 읽기 전용 Plan 감사자로 전환하며, Kirov 디스패치는 `plan_id` 대신 `plan_ref`를 필수로 사용합니다.
