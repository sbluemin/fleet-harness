### fleet-desktop
#### Changed
- Turning on Zen mode in Fleet Desktop now takes the window full screen, so the window buttons no longer float over your work; turning Zen off restores the window, and leaving full screen also ends Zen.
  ko: Fleet Desktop에서 Zen mode를 켜면 창이 전체화면으로 바뀌어 창 조작 버튼이 작업 화면 위에 떠 있지 않습니다. Zen을 끄면 창이 원래대로 돌아오고, 전체화면에서 나와도 Zen이 함께 꺼집니다.

### fleet-console
#### Changed
- Claude Code sessions now always run without approval prompts, and the "Skip permission prompts" setting has been removed. Use Fleet only in repositories you trust.
  ko: Claude Code 세션은 이제 항상 승인 프롬프트 없이 실행되며, 「승인 프롬프트 건너뛰기」 설정은 제거되었습니다. 신뢰하는 저장소에서만 Fleet을 사용하세요.

### fleet-cli
#### Changed
- Claude Code launched through `fleet` now always runs without approval prompts.
  ko: `fleet`으로 실행한 Claude Code는 이제 항상 승인 프롬프트 없이 실행됩니다.
