### fleet-plugin
#### Added
- [fleet-console] Add a Sync action to the Repository panel: one click runs `git fetch --prune --no-tags` against the current repository context, then refreshes branches, history, worktrees, and changes.
  ko: 저장소 패널에 동기화 동작을 추가합니다 — 한 번의 클릭으로 현재 저장소 컨텍스트에 `git fetch --prune --no-tags`를 실행하고 브랜치·기록·워크트리·변경을 갱신합니다.
- [fleet-console] Opening the Repository panel now auto-syncs when the last fetch is older than 5 minutes, with a status line narrating stale, fetching, synced, skipped, and failed states; failures always keep showing local data.
  ko: 마지막 fetch가 5분보다 오래됐다면 저장소 패널을 여는 것만으로 자동 동기화되며, 상태줄이 stale·진행·완료·건너뜀·실패를 알려줍니다. 실패해도 로컬 데이터는 그대로 표시됩니다.
