### fleet-console
#### Changed
- With "Show Operation location" on, sidebar Operation chips now carry only the git branch, and pointing at a chip opens a compact card with the Operation's status, current location, and start time. The working folder moved off the chip into that card, and the chip's operating tooltip steps aside so the two never overlap.
  ko: 「Operation 위치 표시」를 켜면 사이드바 Operation 칩은 git 브랜치만 싣고, 칩을 겨누면 상태·현재 위치·시작 시각을 담은 짧은 카드가 열립니다. 작업 폴더는 칩에서 그 카드로 옮겨 갔고, 칩의 조작 툴팁은 카드와 겹치지 않도록 물러납니다.
