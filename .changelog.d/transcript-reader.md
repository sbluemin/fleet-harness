### fleet-console
#### Added
- Add an experimental transcript reader that renders a running agent session as markdown in a side panel, opened by a RENDER chip beside ANALYZE and turned on in Settings -> Terminal -> General. The panel receives block kinds, text, and tool names only, reduces a tool result to its size, and reveals an arriving block progressively without ever animating history.
