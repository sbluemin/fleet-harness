#### Added
- The Commodore chat now shows when the Claude Code CLI is missing or signed out, blocks sending until it is ready, and keeps your draft.
  ko: 사령관 채팅이 Claude Code CLI가 없거나 로그인되지 않은 상태를 알리고, 준비될 때까지 보내기를 막으며 초안을 남깁니다.

  ko: 그 이유로 메시지를 처리하지 못하면 채팅이 설치·로그인 방법과 함께 원인을 보여 주고, 저절로 다시 시도하지 않습니다.
