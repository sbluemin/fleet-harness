### fleet-plugin
#### Added
- [fleet-console] Add Claude to the AI Gateway settings, above the translated providers, with the haiku, sonnet, and opus aliases.
  ko: AI Gateway 설정에 Claude를 번역 프로바이더보다 위에 추가하고 haiku, sonnet, opus alias를 제공합니다.
- [fleet-console] Expose enabled Claude models as subagents, so a gateway session can hand work to the session's own subscription.
  ko: 활성화한 Claude 모델을 서브에이전트로 노출해, 게이트웨이 세션이 세션 자체 구독으로 작업을 넘길 수 있습니다.

### fleet-core
#### Added
- [core-ai-gateway] Catalog the host's own Claude models so a caller can weigh them against the translated providers. The gateway never executes them: they stay out of the Claude Code model discovery response, and requests naming them are relayed to Anthropic unchanged.
  ko: 호스트 자신의 Claude 모델을 카탈로그에 실어 번역 프로바이더와 나란히 비교할 수 있게 합니다. 게이트웨이는 이 모델을 실행하지 않습니다 — Claude Code 모델 discovery 응답에서 제외되고, 해당 모델을 지목한 요청은 Anthropic으로 그대로 중계됩니다.
- [fleet-admiral] Report the exposed Claude models in gateway_models with their constraints and measured role fit, so quota-based routing can compare them with every other provider.
  ko: 노출된 Claude 모델을 제약과 측정된 role fit과 함께 gateway_models에 보고해, quota 기반 라우팅이 다른 프로바이더와 동일하게 비교할 수 있습니다.
