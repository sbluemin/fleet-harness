### fleet-console
#### Added
- Claude Gateway operations can switch from the terminal to a chat view that continues the same session through the Claude Agent SDK, replays earlier turns, streams new turns live, and takes replies only through Quick Launch; the terminal reopens on demand with the full history intact.
  ko: Claude Gateway Operation을 터미널에서 채팅 뷰로 전환할 수 있습니다. 같은 세션이 Claude Agent SDK로 이어지고, 이전 턴이 재생되며, 새 턴은 실시간으로 스트리밍되고, 회신은 Quick Launch로만 들어옵니다. 터미널은 언제든 전체 기록을 유지한 채 다시 열 수 있습니다.
