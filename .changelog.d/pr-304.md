### fleet-console
#### Added
- [fleet-console] Add a companion panel layout: an agent operation can open dedicated side panels next to its terminal while peers stay preserved, and closing the layout fully restores the Map state.
  ko: 컴패니언 패널 레이아웃을 추가합니다. 에이전트 Operation이 터미널 옆에 전용 패널들을 열 수 있고, 다른 패널 상태는 보존되며 레이아웃을 닫으면 Map 상태가 완전히 복원됩니다.

### fleet-plugin
#### Added
- [fleet-plugin] Add Session Analyst to the terminal plugin: an in-panel ANALYZE handle opens a transcript-grounded analysis chat with CLI, model, and effort selection, streaming answers with event citations, and sandboxed interactive HTML artifacts.
  ko: 터미널 플러그인에 Session Analyst를 추가합니다. 인-패널 ANALYZE 핸들로 트랜스크립트 기반 분석 채팅을 열고 CLI·모델·effort를 선택할 수 있으며, 이벤트 인용이 포함된 스트리밍 답변과 sandbox 인터랙티브 HTML 아티팩트를 제공합니다.

### fleet-core
#### Added
- [fleet-core] Add the fleet-analyst package: a read-only session analysis runtime with defensive transcript indexing, credential redaction, bounded MCP analysis tools, and an in-memory multi-turn analyst session.
  ko: fleet-analyst 패키지를 추가합니다. 방어적 트랜스크립트 인덱싱, 자격증명 마스킹, 경계 있는 MCP 분석 도구, 인메모리 멀티턴 분석 세션을 갖춘 읽기 전용 세션 분석 런타임입니다.
