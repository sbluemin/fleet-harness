### fleet-console
#### Changed
- Tool panels, Settings, and Quaker Aides now share the Objectives panel's solid surfaces in every theme, so the map no longer shows through them even with Liquid Glass on.
  ko: 도구 패널·설정·퀘이커 부관이 모든 테마에서 Objectives 패널과 같은 불투명 면을 써서, 리퀴드 글래스를 켜도 뒤의 지도가 비치지 않습니다.

#### Removed
- Removed the Tool panel opacity setting, since tool panels are now always opaque.
  ko: 도구 패널이 항상 불투명해져 「도구 패널 불투명도」 설정을 없앴습니다.
