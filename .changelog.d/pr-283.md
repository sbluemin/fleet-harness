### fleet-cli
#### Added
- [fleet-cli] Expose workspace-scoped Fleet Plan read and verification tools to the host and authority-scoped Plan tools to Carrier executors.
  ko: 호스트에는 workspace 범위의 Fleet Plan 읽기 및 검증 도구를, Carrier executor에는 권한별 Plan 도구를 제공합니다.

### fleet-console
#### Changed
- [fleet-console] Read Console Plans from the shared Fleet data directory workspace boundary instead of repository-local `.fleet/plans` directories.
  ko: Console Plan을 저장소 로컬 `.fleet/plans` 디렉터리 대신 공유 Fleet data directory의 workspace 경계에서 읽습니다.

### fleet-plugin
#### Added
- [fleet-plans] Equip Terminal-launched host and Carrier agents with workspace-scoped Fleet Plan tools.
  ko: Terminal에서 실행한 호스트 및 Carrier agent에 workspace 범위의 Fleet Plan 도구를 제공합니다.

### fleet-core
#### Added
- [core-infra] Resolve stable cross-platform workspace directories under the Fleet data directory and guard their cwd identities against collisions and unsafe paths.
  ko: Fleet data directory 아래에서 안정적인 cross-platform workspace 디렉터리를 해석하고 cwd identity의 충돌 및 안전하지 않은 경로를 방지합니다.
- [fleet-plans] Add deterministic PlanRef and TaskRef storage, linting, compact execution reads, task completion marking, and Plan-state verification tools.
  ko: 결정론적 PlanRef 및 TaskRef 저장, lint, compact 실행 조회, 태스크 완료 마킹, Plan 상태 검증 도구를 추가합니다.
- [fleet-carriers] Make Kirov author validated Plans through Plan tools and make Ohio execute explicit same-Lane TaskRefs with one compact Plan read per dispatch.
  ko: Kirov가 Plan 도구로 검증된 Plan을 작성하고 Ohio가 dispatch마다 한 번의 compact Plan 조회로 명시적인 동일 Lane TaskRef를 실행하도록 합니다.
