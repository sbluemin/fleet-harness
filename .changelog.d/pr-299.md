### fleet-console
#### Added
- [fleet-console] Let Codex wiki entries be edited with AI directly inside the reading view: drag-select text to add floating comment annotations, batch-send them from a floating dock with CLI, model, and effort selectors, then review AI changes as a rendered document diff with highlighted and removed blocks before applying or discarding the draft in place.
  ko: Codex 위키 엔트리를 리딩 화면 안에서 바로 AI로 편집합니다: 텍스트를 드래그해 플로팅 코멘트 어노테이션을 추가하고, CLI·모델·effort 선택기를 갖춘 플로팅 도크에서 일괄 전송한 뒤, AI 변경을 하이라이트·삭제 블록이 표시된 렌더 문서 diff로 확인해 그 자리에서 반영하거나 폐기합니다.
- [fleet-console] Run Cowork editing through a terminal-free headless agent session whose edits accumulate in a durable per-entry draft, then apply them once through the audited wiki patch pipeline with base version and revision checks.
  ko: Cowork 편집을 터미널 없는 헤드리스 에이전트 세션으로 실행하고, 변경을 엔트리별 durable 초안에 누적한 뒤 base 버전·리비전 검증을 거쳐 감사되는 위키 패치 파이프라인으로 한 번에 반영합니다.

### fleet-core
#### Added
- [fleet-wiki] Add session-scoped Cowork draft tools for reading, exact-replace editing, and full rewriting of one injected draft, kept out of the global wiki tool registry.
  ko: 주입된 초안 하나를 읽고, 정확 치환으로 편집하고, 전체 재작성하는 세션 한정 Cowork draft 도구를 추가하며 전역 위키 도구 레지스트리에는 등록하지 않습니다.
- [core-unified-agent] Add a provider-neutral host file access deny policy for ACP file callbacks and bridge Codex MCP tool approval elicitations into permission requests with protocol-level server and tool provenance.
  ko: ACP 파일 콜백에 대한 provider 중립 호스트 파일 접근 거부 정책을 추가하고, Codex MCP 도구 승인 elicitation을 프로토콜 수준 서버·도구 출처 정보와 함께 권한 요청으로 브리지합니다.
