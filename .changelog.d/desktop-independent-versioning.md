section: Changed
---

- [fleet-console] Fleet Console Desktop shell releases now use independent versioning starting at 0.1.0: the shell is rebuilt only when it changed since its last build, and unchanged releases carry the previous shell installers forward so every GitHub Release still ships them.
  ko: Fleet Console Desktop 셸 릴리스가 0.1.0부터 시작하는 독립 버저닝을 사용합니다: 셸은 마지막 빌드 이후 변경이 있을 때만 다시 빌드되고, 변경이 없는 릴리스는 이전 셸 설치본을 이월해 모든 GitHub Release에 설치본이 계속 포함됩니다.
