### fleet-console
#### Added
- A created access link states what it opens, next to the link itself. A full link warns that it opens a console session able to run commands on this machine, and a monitoring-only link carries no such line because it cannot.
  ko: 만들어진 액세스 링크가 무엇을 여는지를 링크 바로 옆에서 말합니다. full 링크는 이 기계에서 명령을 실행할 수 있는 콘솔 세션을 연다고 경고하고, monitoring 전용 링크는 명령을 실행하지 못하므로 그 문장이 붙지 않습니다.
