### fleet-console
#### Added
- Remote access introduces itself. The host chip in the command band carries a one-off highlight explaining that another device can reach this console, and opening the Remote access section in Settings walks it card by card: the consoles you can jump to, the address this console answers on, its fingerprint, and how an access link is handed out. Finishing the walkthrough retires the chip highlight, and the link step is skipped while the listener is off.
  ko: 원격 접속이 스스로를 소개합니다. 커맨드 밴드의 호스트 칩에 다른 기기가 이 콘솔에 닿을 수 있다는 안내가 한 번 뜨고, 설정의 원격 접속 섹션을 열면 섹션을 카드 단위로 짚어 갑니다 — 건너갈 수 있는 콘솔 목록, 이 콘솔이 응답할 주소, 지문, 그리고 액세스 링크를 건네는 방법입니다. 안내를 끝내면 칩 하이라이트는 다시 뜨지 않고, 리스너가 꺼져 있는 동안에는 링크 단계가 빠집니다.
- Remote access is marked experimental wherever it is reached: the Settings section header and its navigation entry, the saved-hosts list in the host switcher, the notice shown while another device holds control, and the page a browser lands on at the remote address. Pasting an access link states that how links and pairings behave can still change between releases.
  ko: 원격 접속은 닿는 자리마다 실험 기능으로 표시됩니다 — 설정 섹션 머리와 내비게이션 항목, 호스트 스위처의 저장된 호스트 목록, 다른 기기가 제어를 쥔 동안 뜨는 안내, 그리고 원격 주소로 브라우저가 닿았을 때의 안내 페이지입니다. 액세스 링크를 붙여넣는 화면은 링크와 페어링이 처리되는 방식이 릴리스마다 달라질 수 있다고 알립니다.
