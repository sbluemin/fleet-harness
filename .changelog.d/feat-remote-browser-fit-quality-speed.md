### fleet-desktop
#### Added
- While you control a remote Fleet Browser, the page is laid out for your window instead of the other computer's, and it returns to the other computer's size when you stop.
  ko: 원격 플릿 브라우저를 조작하는 동안에는 상대 컴퓨터의 크기가 아니라 내 창에 맞춰 페이지가 배치되고, 조작을 멈추면 상대 컴퓨터의 크기로 돌아옵니다.
- The tools menu can change the remote view's streaming quality, from data saver to sharp.
  ko: 도구 메뉴에서 원격 화면의 스트리밍 화질을 데이터 절약부터 선명까지 바꿀 수 있습니다.

#### Changed
- Remote keyboard and mouse input reaches the other computer with fewer round trips, so typing, dragging and scrolling react faster.
  ko: 원격 키보드·마우스 입력이 더 적은 왕복으로 상대 컴퓨터에 닿아, 타이핑·드래그·스크롤이 더 빨리 반응합니다.
