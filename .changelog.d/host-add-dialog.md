### fleet-console
#### Added
- Adding another console starts where you pick one. `Add host...` sits in the host chip's list in the command band and opens a window for the access link, so pasting one no longer means a trip to Settings. Settings keeps the saved consoles and opens the same window from its own button. Closing the window while the certificate is still being checked cancels the whole add, so nothing is saved.
