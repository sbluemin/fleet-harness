# Agent Runtime

Owns tool vocabulary, MCP serving, Claude SDK execution mechanics, and shared Fleet execution policy. Updates and Gateway model/provider semantics belong to their features.

## Boundaries

- `src/tools/`, `src/mcp/`, and `src/claude/` are substrate. They must not import `src/fleet/`; Fleet identities, prompts, and tool allowlists belong to that policy layer or an injected caller port.
- `src/fleet/` owns shared launch specifications and policy, not UI, process spawning, host state, or Gateway catalogs. Model discovery and pre-rendered delegation identities are injected values.
- Foundation imports neither feature, core, CLI, nor plugin implementations or contracts. Public entrypoints are `/tools`, `/mcp`, `/claude`, and `/fleet`; do not import another module's source paths.
- Each MCP session owns its bearer token, scope, and pending calls. Disposal must not close an injected shared HTTP listener, affect another session, or retain child processes.
- Whoever hands a child internal MCP sessions and external servers must call `assertInternalMcpTokensNotShared` before spawning. Internal tokens must never reach an external server.
- `McpServerConfig.toolTimeoutSeconds` is seconds; providers convert units at their boundary.
- Public isolation uses a generic scope identity; Fleet mapping and host-session tool narrowing stay in caller policy.
- `src/claude/vendor-sdk.ts` is the sole vendor SDK import site. Keep `/claude` out of other entrypoint runtime graphs.
- `assets/hooks/` is the authoring source; `src/fleet/agent-cli/assets.generated.ts` is generated by `scripts/generate-fleet-admiral-assets.mjs`, never hand-edited.
- Gateway hosts carry one concise routing entrypoint in their system prompt, not Fleet skills or per-turn reminders. Detailed routing resources belong to AI Gateway; assigned agents must not redelegate without explicit authorization.
- Wiki mutations and approval remain host-only; runtime policy does not grant that authority.
