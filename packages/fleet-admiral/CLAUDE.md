# fleet-admiral

Fleet's Admiral policy layer for tools, Agent CLI activation, delegation-policy hooks, and Fleet runtime assembly.

## Directory index

| Directory | Responsibility |
|---|---|
| `src/agent-cli/` | Provider activation, launch specification, and Fleet rendering |
| `src/agent-runtime/` | Fleet MCP and executor runtime assembly |
| `assets/hooks/` | Authoring source for embedded Fleet hook scripts |
| `assets/ai-gateway/` | Authoring source for on-demand Gateway MCP policy resources |
| `tests/` | Asset, launch, hook, and runtime contracts |

## Constraints

- This package owns Fleet policy and launch/runtime specifications, not host UI, PTY, process spawning, browser lifecycle, or host-owned application state.
- Host integrations and optional domain tools enter through explicit dependencies; this package must not import runtime hosts.
- Wiki mutation, staging, lint, schema, and patch approval / rejection are host-only; the host performs Fleet Wiki operations directly.
- Gateway hosts carry one concise Fleet routing entrypoint appended to their system prompt, but no Fleet skills. Keep detailed policy in on-demand `fleet-ai-gateway` resources; server instructions own resource discovery, not a duplicate behavioral policy. Assigned subagents must not be encouraged to redelegate without explicit authorization.
- Fleet-authored Gateway instructions and resource response prose are English. Preserve model identifiers and external data verbatim.
- `assets/ai-gateway/` owns routing policy, identity selection, and live roster preflight. Host-native Agent/Workflow descriptions own execution mechanics and opt-in. Preserve host integration responsibility, isolated writers, and explicit failure reporting. Do not reintroduce per-turn reminders or PreToolUse spelling gates.
- Public exports are a deliberate root whitelist. Do not add wildcard exports, compatibility subpaths, or source deep-import contracts.
- `assets/hooks/` and `assets/ai-gateway/` are authoring sources of truth; `src/agent-cli/assets.generated.ts` is generated by `scripts/generate-fleet-admiral-assets.mjs` and must not be hand-edited.
