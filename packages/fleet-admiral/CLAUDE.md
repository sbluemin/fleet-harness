# fleet-admiral

Fleet's Admiral policy layer for tools, Agent CLI activation, delegation-policy hooks, and Fleet runtime assembly.

## Directory index

| Directory | Responsibility |
|---|---|
| `src/agent-cli/` | Provider activation, launch specification, and Fleet rendering |
| `src/agent-runtime/` | Fleet MCP and executor runtime assembly |
| `assets/hooks/` | Authoring source for embedded Fleet hook scripts |
| `assets/skills/` | Authoring source for compact on-demand Fleet skills |
| `tests/` | Asset, launch, hook, and runtime contracts |

## Constraints

- This package owns Fleet policy and launch/runtime specifications, not host UI, PTY, process spawning, browser lifecycle, or host-owned application state.
- Host integrations and optional domain tools enter through explicit dependencies; this package must not import runtime hosts.
- Wiki mutation, staging, lint, schema, and patch approval / rejection are host-only; the host performs Fleet Wiki operations directly.
- Gateway sessions carry no Fleet system prompt. Compact Fleet guidance is exposed only as on-demand plugin skills; it must never recreate an always-on prompt layer.
- Delegation policy is split deliberately: the `delegation` skill owns semantic execution-graph decisions and requires a `gateway_models` preflight, the skill's own `description` owns routing into it via concrete When-to-use triggers (no per-turn reminder injection), the live Workflow tool owns graph mechanics, the `gateway_models` tool owns the identity roster and its spellings, and embedded hooks validate the resulting pin and handle Workflow receipts. Keep each rule at that owner; do not restate it in the system prompt or another skill.
- Do not gate a hook on a `Skill(<name>)` `if` condition. Claude Code evaluates `if` as a permission rule and matches rule content through the tool's `preparePermissionMatcher`, which the Skill tool does not implement, so such a hook is silently skipped forever. Reach the host through the skill's description and body instead.
- Public exports are a deliberate root whitelist. Do not add wildcard exports, compatibility subpaths, or source deep-import contracts.
- `assets/hooks/` and `assets/skills/` are authoring sources of truth; `src/agent-cli/assets.generated.ts` is generated by `scripts/generate-fleet-admiral-assets.mjs` and must not be hand-edited.
