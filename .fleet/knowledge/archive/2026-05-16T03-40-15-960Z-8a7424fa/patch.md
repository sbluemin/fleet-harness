{"id":"prd-coding-agent-model-cycling","title":"Coding Agent Model Selection and Cycling","tags":["model-cycling","scoped-models"],"created":"2026-05-16T03:40:15.960Z","updated":"2026-05-16T03:40:15.960Z","version":1,"body":"## Overview\nThis document defines the requirements and behavior for model selection and keyboard cycling in the `@sbluemin/fleet-coding-agent`. Following the removal of the interactive scoped-models selector, model management has been simplified to focus on the global active model pool.\n\n## Problem\nIn earlier versions, the complexity of managing a subset of models (legacy \"scoped-models\") via a dedicated TUI overlay created maintenance overhead and user confusion. Users need a predictable, fast way to switch between models without per-session reordering UIs.\n\n## Goals\n- Provide a zero-configuration model cycling experience based on startup flags.\n- Maintain compatibility with existing model selection slash commands.\n- Simplify the internal state by removing redundant model-scoping layers.\n\n## Non-Goals\n- Per-session reordering of the model cycle.\n- Persistent cycling-scope overrides via TUI (legacy scoped-models).\n- Automatic model switching based on task context.\n\n## User Stories\nAs a developer, when I want to quickly test a prompt on a different model, I can use a single keybinding to cycle through the available pool defined at startup.\nAs a power user, when I need a specific model not in the current cycle, I can switch to it directly using the slash command.\n\n## Functional Requirements\n- Cycle models forward via `Ctrl+P` and backward via `Shift+Ctrl+P`.\n- Populate the cycle pool from the `--models` CLI flag or the default provider catalog.\n- Support direct model switching via the `/model` slash command.\n- Display the currently selected model in the editor HUD.\n\n## Acceptance Criteria\n- Pressing `Ctrl+P` successfully switches to the next model in the pool.\n- The HUD updates immediately when the model is changed.\n- The `/model` command opens the full selection UI.\n- No trace of the legacy `/scoped-models` command or UI remains.\n\n## Open Questions\n- None.\n\n## Related\n- [[wiki:prd-harness-btw-overlay]]","rawSourceRef":"raw/2026-05-16-prd-coding-agent-model-cycling-source-a783ba41.md"}
