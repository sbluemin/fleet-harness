2026-05-16T00:00:00.000Z\nupdated: 2026-05-16T00:00:00.000Z\nversion: 1\nsummary: 작업 컨텍스트 오염 없는 일시적 멀티 턴 질의 환경 및 고속 모델 선택 인터페이스 제공\n---\n\n## Overview\n\n`/btw` (By The Way) 명령어는 현재 진행 중인 작업 세션(Host JSONL)을 오염시키지 않으면서, AI 모델에게 즉각적이고 독립적인 질의를 수행할 수 있는 일시적(Ephemeral) 멀티 턴 쿼리 오버레이를 제공합니다. 이 기능은 에디터 영역을 일시적으로 점유하여 사용자가 컨텍스트를 유지한 채 다른 모델의 의견을 묻거나 짧은 대화를 나눌 수 있도록 설계되었습니다.\n\n## Problem\n\n기존의 모델 선택 인터페이스는 다음과 같은 제약 사항으로 인해 사용성이 제한적이었습니다:\n- **렌더링 하드캡**: 표시 가능한 모델 수가 8개로 고정되어, 그 이상의 모델은 목록에서 확인할 수 없었습니다.\n- **스크롤 부재**: 목록이 길어질 경우 현재 선택 지점이 화면 밖으로 사라지는 등 탐색이 불가능했습니다.\n- **검색 기능 전무**: 수많은 모델 중 원하는 모델을 찾기 위해 오직 방향키 탐색에만 의존해야 했습니다.\n- **제한된 이동성**: 대량의 모델 리스트를 빠르게 탐색할 수 있는 페이지 단위 이동이나 끝단 이동 기능이 없었습니다.\n\n## Goals\n\n- **탐색 가시성 확보**: 스크롤 뷰포트를 도입하여 모델 리스트의 크기에 상관없이 안정적인 탐색 환경을 제공합니다.\n- **고속 모델 필터링**: 실시간 부분 문자열(Substring) 검색을 통해 원하는 모델을 즉시 찾고 전환할 수 있도록 합니다.\n- **사용자 경험 고도화**: 페이지 이동(PgUp/PgDn), 시작/끝 이동(Home/End) 등 표준적인 리스트 탐색 조작을 지원합니다.\n- **컨텍스트 격리**: 모든 질의와 응답이 호스트 세션에 기록되지 않도록 하여 깨끗한 작업 환경을 유지합니다.\n\n## Non-Goals\n\n- 호스트 채팅 세션(JSONL)으로의 대화 내용 저장 또는 병합.\n- 오버레이 종료 후 대화 상태의 영구적인 보존.\n- 모델의 개별 파라미터(Temperature, Top-P 등)를 세부 설정하는 UI 제공.\n\n## User Stories\n\n- **As a** 대원수, **when** 작업 중 특정 로직에 대해 다른 모델의 의견이 궁금할 때, **then** `/btw` 명령어를 입력하여 즉시 독립적인 대화창을 열 수 있습니다.\n- **As a** 대원수, **when** 수십 개의 모델 중 특정 모델(예: Claude 3.5 Sonnet)을 선택해야 할 때, **then** 모델 선택기를 열고 \"sonnet\"을 타이핑하여 즉시 해당 모델로 포커스를 이동할 수 있습니다.\n- **As a** 대원수, **when** 리스트의 맨 아래에 있는 모델을 선택하고 싶을 때, **then** `End` 키를 눌러 즉시 마지막 항목으로 이동할 수 있습니다.\n- **As a** 캐리어, **when** 오버레이에서 복잡한 질의를 수행한 후 원래 에디터로 돌아가고 싶을 때, **then** `Esc` 키를 눌러 현재 세션을 깔끔하게 종료할 수 있습니다.\n\n## Functional Requirements\n\n- **스크롤 가능한 뷰포트**:\n    - 모델 선택기 드롭다운은 최대 7개의 행을 동시에 표시하며, 선택 위치에 따라 슬라이딩 윈도우 방식으로 스크롤됩니다.\n    - 리스트 상단/하단에 추가 항목 존재 여부를 알리는 컷오프 인디케이터(`↑`, `↓`, `↕`)를 표시합니다.\n- **실시간 Substring 검색**:\n    - 드롭다운이 열린 상태에서 타이핑 시 즉시 필터링이 시작됩니다.\n    - 검색 대상은 모델 이름, ID 및 제공자 이름을 포함합니다.\n    - 검색어 입력 시 첫 번째 매치 항목으로 자동 포커스(Selection Sync)가 이루어집니다.\n- **고급 내비게이션**:\n    - `PgUp`/`PgDn`: 7개 항목 단위 이동.\n    - `Home`/`End`: 리스트의 최상단/최하단 즉시 이동.\n- **지능형 Esc 처리**:\n    - 검색어가 입력된 상태에서 `Esc`는 검색어만 초기화합니다.\n    - 검색어가 없는 상태에서 `Esc`는 드롭다운을 닫거나 오버레이를 종료합니다.\n- **상태 인디케이터**:\n    - 현재 선택된 인덱스와 전체 모델 수를 `(선택/전체)` 형식으로 표시합니다.\n\n## Acceptance Criteria\n\n- [ ] 20개 이상의 모델이 존재하는 환경에서 `PgDn` 및 `End` 키를 통해 목록 끝까지 정상적으로 도달할 수 있는가?\n- [ ] 검색어 입력 시 대소문자 구분 없이 부분 일치하는 모델만 리스트에 남는가?\n- [ ] 검색 결과가 없는 경우 \"(no matches)\" 안내 메시지가 출력되는가?\n- [ ] 오버레이에서 수행한 질의가 실제 호스트 세션 파일(JSONL)에 기록되지 않는가?\n- [ ] 모델 전환 후 `Enter`를 눌렀을 때 해당 모델로 질의가 정상 전송되는가?\n\n## Open
